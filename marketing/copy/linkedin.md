Most note-taking tools ask you to trust them with the only copy of your
thinking.

NeonNotes takes the other position: a vault is a folder of plain Markdown files.
No database, no account, no proprietary format. You can read every note in any
editor, back it up with rsync, version it with git, or open it ten years from
now without this app existing.

Around that constraint it still behaves like a modern editor: live syntax
highlighting, rendered preview, tag-aware search, wiki links with backlinks, a
radial map of how notes connect, inline charts, and export to PNG, GIF, HTML or
Markdown.

Two devices can sync the vault over a local network — no cloud service in the
middle. (Worth saying plainly: that transport is not encrypted yet, so it is for
trusted networks.)

It is built in Godot 4.7, which is an unusual choice for a text editor and the
reason it looks like an arcade cabinet instead of a spreadsheet. Linux, Windows
and Android from the same codebase. AGPL-3.0.

Source and screenshots: github.com/DigitalKI/neonnotes

If you keep notes for a decade, the file format is the feature.
