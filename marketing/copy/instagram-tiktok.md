## Caption

Your notes should outlive the app.

NeonNotes keeps every note as a plain .md file in a folder you own — then renders
it like a CRT arcade cabinet. Wiki links, a radial graph, inline charts, export
to PNG/GIF/HTML, LAN sync with no cloud.

Godot 4.7 · Linux / Windows / Android · AGPL
Link in bio → github.com/DigitalKI/neonnotes
