**1/**
Your notes app shouldn't be a service.

NeonNotes is a note-taking app where every note is a plain .md file in a folder
you own — wrapped in a CRT arcade glow.

Built with Godot 4.7. Runs on Linux, Windows and Android.

**2/**
No database. No account. No export button, because there's nothing to export.

grep it. rsync it. git it. Drop the folder in Dropbox and the notes are just
files in Dropbox.

**3/**
It still edits like a real notes app: live syntax highlighting, rendered
preview, slash menu for headings/tables/charts, tags with autocomplete, and one
search box that takes keywords and #tags together.

**4/**
The parts I keep opening it for:

- [[wiki links]], backlinks, and a radial vault graph
- charts written as a fenced block, rendered live
- export to PNG, animated GIF, HTML or Markdown
- two devices syncing over your own LAN, no cloud in the middle
